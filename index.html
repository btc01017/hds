Hyperliquid Request Weight

Подключает MetaMask и отправляет официальный action reserveRequestWeight. Приватный ключ не запрашивается и не сохраняется.

Сначала купи 1 request для проверки. После успешного ответа можно поставить 50 000 (= примерно 25 USDC по текущей ставке 0.0005 USDC/request).
Ожидаемый адрес 0xD8A73dFF235633089AAB07f124b43a50205b57fC
Подключённый адрес —
Ориентировочная стоимость 0.0005 USDC
Текущий API-лимит не загружен

Оплата списывается Hyperliquid с Perps balance. Для reserve должен подписывать основной кошелёк аккаунта.

Готово. Подключи MetaMask.
function getMetaMaskProvider() { const eth = window.ethereum; if (!eth) return null; if (eth.isMetaMask && !eth.isRabby) return eth; if (Array.isArray(eth.providers)) { const mm = eth.providers.find(p => p?.isMetaMask && !p?.isRabby); if (mm) return mm; } return null; }
